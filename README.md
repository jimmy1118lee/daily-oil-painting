# 每日欧洲油画壁纸

每天自动把一幅 **1300–1800 年的欧洲油画**设为 Windows 桌面壁纸，全部来自
世界级博物馆的**公共领域**（Public Domain / CC0）高清藏品。挂机不管，每天一幅。

程序会自动把画作渲染成**与你的屏幕分辨率完全一致**的成品图，所以 4K 屏上
不会变糊，双屏也不会在接缝处出现断层。

---

## 一、它能做什么

| 能力 | 说明 |
| --- | --- |
| 每日自动更换 | 默认每天 **08:30** 换一张，时间可在托盘菜单里改 |
| 关机自动补换 | 到点电脑没开机，开机后会自动补换当天那张（可关闭） |
| 三家博物馆图源 | 大都会艺术博物馆、芝加哥艺术博物馆、克利夫兰艺术博物馆 |
| 严格年代过滤 | 只收创作年代完全落在 1300–1800 之间的作品 |
| 不重复 | 同一幅画在 540 天内不会再出现；轮完一遍自动重新开始 |
| 自适应分辨率 | 每块显示器单独生成一张尺寸完全匹配的图，4K 不变糊、多屏不压扁 |
| 完整构图 | 默认完整显示整幅画（竖构图肖像不会被裁掉），背景是画作本身的模糊版 |
| 作品水印 | 左下角显示「标题 / 作者·年代 / 博物馆·版权」，可关掉 |
| 图形控制面板 | 双击桌面快捷方式打开，不依赖托盘图标 |
| 托盘控制 | 立刻换一张、收藏、查看详情、暂停、改时间、开机自启开关 |
| **壁纸守护** | 桌面壁纸被系统重置或被别的软件改掉时，**几分钟内自动设回来** |
| **自我修复** | 托盘意外退出后，由计划任务在 10 分钟内自动拉起 |
| 完全离线选图 | 作品目录缓存在本地，日常换壁纸只下载一张图片 |

**图库规模**（首次运行自动抓取，之后 30 天才刷新一次）：

- 大都会艺术博物馆（European Paintings + 雷曼收藏）
- 芝加哥艺术博物馆：服务端精确过滤出 537 幅公共领域欧洲绘画
- 克利夫兰艺术博物馆：666 幅 CC0 欧洲绘画

总量约 1400 幅起，按每天一幅算可以连续 3 年以上不重复。

## 二、安装

**要求**：Windows 10 / 11 + Python 3.8 以上（[下载](https://www.python.org/downloads/)，
安装时记得勾选 *Add python.exe to PATH*）。

双击 **`install.bat`**，它会自动完成：

1. 把程序复制到 `%LOCALAPPDATA%\Programs\DailyOilPainting`
2. 安装依赖（`Pillow`、`pystray`，只在这时候需要联网）
3. 生成程序图标、写入默认配置
4. 设置开机自动启动（**用两个计划任务实现，见下面「为什么不用注册表自启」**，不需要管理员权限）
5. 在**桌面**和**开始菜单**建立「每日欧洲油画壁纸」快捷方式
6. 启动托盘程序

> 第一次启动会自动抓取作品目录（大约 1–4 分钟，取决于网速）。
> 抓完之后托盘会把第一张壁纸换上，之后每天都是秒换。

### 为什么不用注册表自启

早期版本把自启写在 `HKCU\...\CurrentVersion\Run` 里，结果踩了坑：
Windows 自带的"启动项"管理、以及各种清理/管家类工具，会把这个项在
`StartupApproved\Run` 里标记成**禁用**（值 `03 00 ...`）。
注册表项看着还在，但开机**根本不会执行**——用户的机器就这样静默失效过一次，
中间重启几次后托盘再没起来，壁纸也停在旧图上没人管。

现在改成两个计划任务（`schtasks`，同样不需要管理员权限）：

| 任务 | 触发 | 作用 |
| --- | --- | --- |
| `DailyOilPainting` | 用户登录时 | 拉起后台托盘 |
| `DailyOilPainting-Watchdog` | 每 10 分钟 | 发现托盘不在就拉起来 |

两个任务都只执行一个几十毫秒就退出的看门狗脚本，托盘由它派生出去，
所以不会撞上"任务运行超过 72 小时被系统结束"的限制。
注册表项仍然会写（作为第二道保险），并且每次开启自启都会顺手把它
在 `StartupApproved` 里的禁用标记改回启用。

## 三、日常使用

**双击桌面上的「每日欧洲油画壁纸」**会打开图形控制面板，这是最直接的入口：

- **正在展出**：深色背景下完整预览画作，显示标题、作者、年代与馆藏；可放大、收藏、查看详情或换一幅画。
- **我的收藏 / 更换记录**：查看真实收藏与历史；选中只预览，点击“设为壁纸”才会应用。
- “不使用竖图”仅限制自动与随机换画。手动从收藏或记录中选中的画作可直接应用，包括竖图；优先使用本地原图，没有原图时使用收藏成品，不必重复下载。
- **底部每日计划**：查看下次更换时间，暂停或恢复自动更换。
- **设置**：调整更换时间、开机补换、自启、不使用竖图、多屏排版、画面适配和作品署名；显示设置在下次换画时应用。
- **设置中的维护工具**：壁纸文件夹、日志、后台启动、固定托盘图标、重建作品库。

关闭控制面板后，托盘继续在后台执行每日计划。托盘自动换画时，打开的窗口会同步更新预览。

登录自启与定时看护任务直接运行 `pythonw.exe main.py watchdog`（独立版直接运行程序自身），不经批处理或命令提示符。重新安装只更新已有任务的启动动作，保留原触发时间与运行身份；首次安装默认每 10 分钟检查一次后台。

后台托盘负责每天的自动更换，开机自启，平时不用管。

**单击托盘画框图标会打开控制面板，不会更换壁纸。** 手动换图请在控制面板点击“换一幅画”，或从托盘右键菜单选择“现在换一张”。

**找不到托盘图标？** Windows 11 默认把新出现的托盘图标收进「隐藏的图标」溢出区，
而且系统更新后经常重置。点任务栏右下角的 **`^`** 展开，把画框图标拖到任务栏上即可常驻；
也可以点控制面板里的「把图标固定到任务栏」。

**右键菜单：**

| 菜单项 | 作用 |
| --- | --- |
| 打开控制面板（单击图标同效） | 打开操作界面，不换壁纸 |
| 现在换一张 | 立刻随机换一张 |
| 重新下载当前画作 | 当前图片损坏或想重新渲染时用 |
| 收藏当前画作 | 把成品图 + 原图复制到 `favorites` 目录 |
| 查看画作详情 | 用浏览器打开一个排版好的详情页 |
| 打开馆藏页面 | 跳到博物馆官网该藏品的页面 |
| 打开壁纸文件夹 / 图片缓存 / 日志 | 直接打开对应目录 |
| 暂停自动更换 | 临时不动壁纸 |
| 每日更换时间 | 06:30 / 07:30 / 08:30 / 12:00 / 18:00 / 21:00 / 23:00 |
| 开机自动启动 | 开关自启动 |

**命令行**（在程序目录里执行，或直接双击 `dop.bat` 后接参数）：

```bat
python main.py change              :: 立刻换一张
python main.py change --rebuild-catalog   :: 重建作品库后再换
python main.py info --open         :: 看当前作品并打开详情页
python main.py status              :: 查看运行状态
python main.py catalog             :: 查看作品库统计
python main.py catalog --force     :: 强制重新抓取（约 2-4 分钟）
python main.py set-time 07:00      :: 改每日更换时间
python main.py pause               :: 暂停；加 --resume 恢复
python main.py favorite            :: 收藏当前壁纸
python main.py config get sources.harvard.api_key   :: 查看 Key（自动打码）
python main.py scrub-logs          :: 清除日志里可能残留的 API Key
python main.py uninstall --purge   :: 移除自启并删除缓存
```

## 四、配置

配置文件：`%LOCALAPPDATA%\DailyOilPainting\config.json`
（改完保存即可，托盘每 30 秒重读一次，**不用重启**）

常用项：

```jsonc
{
  "schedule": {
    "time": "08:30",        // 每天几点换
    "catch_up": true,       // 开机补换错过的
    "paused": false
  },
  "date_range": [1300, 1800],   // 年代范围，可收窄，比如 [1400, 1650]

  "selection": {
    "landscape_only": true    // 默认排除竖图；横图和方图保留，按 EXIF 旋转后的实际方向判定
  },

  "image": {
    "style": "fit",         // fit=完整显示整幅画（推荐）
                            // fill=铺满屏幕（会裁掉画面边缘）
                            // center=不放大，原尺寸居中

    "multi_monitor": "each",// 多屏布局（默认每块屏都显示完整画作）
                            //   each    = 每块屏各一份完整版式（推荐）
                            //   primary = 画作只在主屏，其它屏是模糊延伸
                            //   span    = 一整张跨屏图切分
    "background": "blur",   // 留白用画作模糊版；也可设 "color" 用纯色
    "darken": 0.55,         // 背景压暗程度
    "jpeg_quality": 93,
    "show_caption": true,   // 左下角作品信息
    "show_museum": true
  },

  "selection": {
    "recency_days": 540     // 多少天内不重复
  },

  "sources": {
    "met":       { "enabled": true, "weight": 1.0 },
    "artic":     { "enabled": true, "weight": 1.0 },
    "cleveland": { "enabled": true, "weight": 0.8 },
    "harvard":   { "enabled": true, "weight": 0.7,
                   "api_key": "",       // 建议留空用环境变量
                   "cache_days": 14,    // 条款上限，调大无效
                   "target_valid": 400 }
  },

  "advanced": {
    "catalog_ttl_days": 30, // 作品库多久刷新
    "concurrency": 3,       // 并发数，调大会被 Met 限流
    "requests_per_second": 4,
    "keep_archive": false   // 是否按日期留存每天成品图
  }
}
```

用命令行改也可以：

```bat
python main.py config get image.style
python main.py config set image.style fill
python main.py config set date_range "[1400, 1650]"
```

## 五、图源说明

| 图源 | 是否需要 Key | 说明 |
| --- | --- | --- |
| 大都会艺术博物馆 (Met) | 否 | 欧洲绘画 + 雷曼收藏 |
| 芝加哥艺术博物馆 (AIC) | 否 | 图片走 IIIF，需要带特定请求头（程序已处理） |
| 克利夫兰艺术博物馆 (CMA) | 否 | 全部 CC0，清晰度好 |
| 哈佛艺术博物馆 | **需要免费 Key** | 见下面「哈佛接入」一节 |

### 哈佛艺术博物馆接入

申请免费 Key：<https://harvardartmuseums.org/collections/api>

**Key 的存放位置（不会硬编码、不会进 Git、不会写进日志）**，二选一：

```bat
:: 方式一：环境变量（推荐，Key 完全不落盘）
setx DOP_HARVARD_API_KEY "你的KEY"
```

```jsonc
// 方式二：写进 config.json（该文件在 %LOCALAPPDATA% 下，不在代码仓库里）
"sources": { "harvard": { "enabled": true, "api_key": "你的KEY" } }
```

程序做了三层保护：

1. 异常信息与日志里的 URL 一律经过脱敏（`apikey=***`），并有日志过滤器兜底；
2. `config show` / `config get` 显示 Key 时只露前 4 位；
3. 如果 Key 来自环境变量，保存配置时会把它从磁盘内容里剔除，保证"只放环境变量"就真的只在环境里。

遗漏的历史残留可以用 `python main.py scrub-logs` 清掉。

**筛选条件（按官方文档实现）**：

- 服务端：`division:"European and American Art"` + `classification=Paintings` +
  `yearmade=1300-1800` + `hasimage=1`，每页 100 条
- 客户端再收口：年代必须**完整**落在区间内、`imagepermissionlevel == 0`
  （0 才允许任意尺寸显示，1 最多 256px、2 禁止）、文化属于欧洲白名单
  （排掉 American、Argentinian 等）、媒材必须真是绘画（排掉雕塑/器物/素描）
- 保留：标题、作者、年代、媒材、原始馆藏链接（`harvardartmuseums.org` 的藏品页）

**遵守其使用条款**：

- 内容缓存不超过两周 —— 启用哈佛后，作品目录的整体有效期自动压到 **14 天**，
  超过两周的缓存原图也会被自动清理
- 每天不超过 2500 次调用 —— 程序用响应缓存（同一查询 14 天内不重复请求），
  实测第二次抓取是 **0 次接口调用**
- 必须回链 —— 详情页与托盘菜单都有「打开馆藏页面」
- 仅限非商业用途

> **实测提示**：本机网络访问哈佛的图片服务器（`nrs.harvard.edu` /
> `ids.lib.harvard.edu`）会持续返回 **429 Too Many Requests**（换 HTTP 栈、
> 等待、换请求头都无效，同域名下的 IIIF manifest 却是 200），
> 因此当前**能取到元数据、取不到图片**。程序对此做了容错：取图失败会自动换下一幅，
> 并给连续失败的图源降权；等网络恢复后哈佛作品会自动重新出现，无需改配置。

## 七、常见问题

**Q：壁纸一直不变，或者变回了 Windows 默认壁纸？**

先跑一次体检，它会直接告诉你卡在哪：

```bat
python main.py diagnose
```

重点看三行：

- **后台托盘**：如果是「未运行」，说明负责每天更换的进程没了。
  程序自带看门狗（计划任务 `DailyOilPainting-Watchdog`，每 10 分钟一次），
  正常情况下 10 分钟内会自己拉起来；也可以立刻手动跑 `python main.py watchdog`。
- **开机自启**：如果是「未开启」，打开控制面板把「开机自动启动」勾上。
  注意各种「启动项优化 / 开机加速」工具可能关掉自启，程序现在用计划任务实现，
  不受那个开关影响。
- **壁纸是否还是本程序的**：如果是「否」，说明壁纸被系统或其他软件改掉了。
  只要托盘在运行，**壁纸守护每 5 分钟会检查一次并自动设回来**
  （想自己换壁纸就先在托盘或控制面板里「暂停自动更换」）。

**Q：为什么壁纸会被改掉？**
常见原因：系统大版本更新后重置主题、装了新的壁纸/美化软件、某些"桌面整理"工具。
这些都不是本程序造成的，但程序现在会主动把壁纸守护回来。

**Q：第一次换壁纸等了很久？**
在建作品库。Met 的明细接口必须一条条查，程序故意做了限速（4 次/秒）以免被
封，所以需要几分钟。**这一步 30 天才做一次**，之后换壁纸是秒换。

**Q：日志里出现「Met 接口失败率偏高」？**
短时间内请求太多被临时限流了。程序会自动退避重试；如果还是失败，等几分钟再
执行 `python main.py catalog --force` 即可，或者把 `concurrency` 调到 2。

**Q：竖构图油画两边的模糊背景是什么？**
那是画作自身的模糊放大版，用来填充宽屏留白，比黑边好看。想让它铺满屏幕就把
`image.style` 改成 `fill`（代价是会裁掉画面上下或左右的边缘）。

**Q：双屏壁纸怎么处理？**
程序读取每块显示器的物理分辨率，**给每块屏单独生成一张尺寸完全匹配的图**，
再通过 `IDesktopWallpaper` 接口逐屏设置。这样完全不依赖系统自己的缩放逻辑——
实测 Windows 11 常常无视注册表里的"跨屏"设置，会把整张大图压进每一块屏，
导致画作被压扁并在两块屏上重复。

多屏布局默认是 `each`：**每块屏都显示一份完整的画作**（中间是画，两侧是模糊延伸）。
之所以不默认把画只放主屏，是因为**程序无法判断哪块屏物理上在左边**——
Windows 只提供虚拟坐标，而虚拟左右和物理左右并不总是一致。
如果想换成"画作只在主屏、其它屏只有模糊延伸"，把 `image.multi_monitor` 改成 `primary`。

**Q：为什么作品库里排除了很多藏品？**
只收真正的绘画：克利夫兰的「European Painting and Sculpture」部门里，
雕塑/器物占了近三成（铜雕、大理石、陶塑、镀金木雕…），大都会的「欧洲绘画」部门里
也混着象牙器和素描。程序按**媒材**（oil / tempera / fresco）过滤，
不是绘画的一律不要。

**Q：怎么彻底卸载？**
双击 `uninstall.bat`。想连缓存和历史一起删就执行
`uninstall.bat --purge`，或先手动把壁纸换回自己喜欢的再卸载。

**Q：程序会不会偷偷联网？**
只在两种情况下联网：① 每 30 天刷新一次作品目录；② 每天下载当天那一张画作。
除此之外不发送任何数据，也没有任何账号体系。

```
        ├── icon.py             程序图标 / 托盘图标
        ├── report.py           详情页 HTML
        ├── http.py             限速 + 退避重试的 HTTP 客户端
        └── sources/            各博物馆接口
            ├── met.py  artic.py  cleveland.py  harvard.py
```

想加一家新博物馆：在 `src/dop/sources/` 里加一个模块，实现
`fetch(cfg, http, log, progress) -> list[work]`，用 `base.make_work()` 构造返回值，
再到 `sources/__init__.py` 的 `SOURCES` 里注册一行即可。
